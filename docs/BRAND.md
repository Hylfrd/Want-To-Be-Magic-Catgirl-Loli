# Wayglint

正式产品名称：**Wayglint**。固定为首字母大写，其余小写；不写作 WayGlint 或 WAYGLINT。

英文描述：**Campus maps & AR navigation**。用于需要说明产品用途的页面，不作为名称的一部分。

Way 表示路径，Glint 表示短暂可见的光。组合名称表达“让前方的路变得可见”，对应校园地图、跨楼层路线与摄像头中的 AR 指引。名称不限制某所学校，也不把 AI 技术名写进产品名。

## 品牌设计基线：位置标记＋AR 取景框

浅天蓝底、白色位置标记和四个简洁的取景框角。位置标记对应地图定位，取景框对应在真实空间中查看 AR 指引。使用纯色与留白，不加入文字、地图纹理、光效或渐变。

图标 SVG 的 `viewBox` 为 `0 0 256 256`，背景圆角 56。保留原始比例，不独立拉伸或旋转。已查看 24、32、48、64 px 的实际渲染；平台接入后仍需在 launcher 的实际遮罩和主题下检查。

## 界面主题与设计元素

视觉方向是**浅天蓝、清晰留白、简洁几何和直接的导航信息**。品牌代表校园地图、路线与 AR 指引；Catgirl 只是旧开发代号，不能据此生成猫、猫耳、动漫角色、魔法主题或吉祥物，也不能作为用户看到的产品标题。

沿用 DRD 已选的 Material Design 3：管理网页使用 Vuetify `md3` blueprint，Android 使用 Material Components／Material3 的 DayNight 主题。品牌通过现有主题颜色、标题、图标和组件样式接入，不另建主题框架或更换 UI 库。

浅天蓝＋白色用于应用 icon 和品牌标记；浅蓝不是浅色界面的白字按钮颜色，文字和交互图标需满足所在组件的对比度要求。使用上表显式颜色，不能依赖默认紫色主题或设备壁纸生成的动态配色来替换品牌。状态、错误、警告、成功、路线类别、当前楼层和 AR 跟踪状态的语义优先于品牌配色；不把所有路线或状态都染成浅蓝，也不只用颜色传递状态。

文字沿用平台界面字体与 MD3 的文字层级，圆角、间距和交互状态复用现有组件。保留可辨认的 focus、pressed、disabled 和 error 状态。地图、三维预览及摄像头画面优先呈现真实空间和路线信息；品牌标记放在应用入口和导航栏等合适位置，不遮挡 AR 视野，不在每张卡片重复堆放 logo。

W01 接入网页标题、页面品牌入口、favicon、明暗主题及共用组件颜色；A01 接入应用显示名称、launcher／单色图标和 Material3 明暗主题资源。后续 W02／W03、A02–A05 继承这些基线，不自行创建替代产品名或视觉主题；它们仍按 DRD 实施地图、路线和状态行为。
